🔍 اختبار فلترة المنتجات بالخصائص

اختبار 1️⃣: فلترة بخاصية واحدة

البحث عن كل المنتجات اللي عندها Storage = 256GB

{
  "attributes": {
    "Storage": ["256GB"]
  }
}

اختبار 2️⃣: فلترة بقيم متعددة لنفس الخاصية

البحث عن المنتجات اللي عندها Storage = 256GB أو 512GB أو 1TB 

{
  "attributes": {
    "Storage": ["256GB", "512GB", "1TB"]
  }
}

اختبار 3️⃣: فلترة بخصائص متعددة

البحث عن المنتجات اللي عندها Storage = 256GB و Color = Natural Titanium 

{
  "attributes": {
    "Storage": ["256GB"],
    "Color": ["Natural Titanium"]
  }
}

اختبار 4️⃣: كل المنتجات (بدون فلترة)

عرض كل المنتجات المتاحة لمعرفة الخصائص الموجودة
